# FGC application scope

Read [../AGENTS.md](../AGENTS.md) for the canonical workspace instructions and
skill index. All agent skills and their supporting files are in
[../.agents/skills](../.agents/skills); no project-local copy is maintained.

Run this application's npm, Nx, Git and database commands from this directory.
Resolve application paths in skills against this repository; resolve skill links
against their containing file. Supplied context is in `../contexts/`.
