# Parity audit (phase 3) — 2026-09-23

Method: each approved function M01–M30 (`contexts/fgc-mvp/migracao-escopo-paridade.md`)
was compared with the legacy `firstglobal-ops` source and exercised in the running
app. Evidence is limited to **synthetic data on the mock stack** (real UI, real REST
API, real SQL on in-memory PGlite; identity provider replaced). Nothing here proves
behaviour against real Supabase, SMTP, push delivery or installed devices.

Legend: **E2E** = Playwright `fullstack` project (`apps/fgc-web/e2e-mock`),
**Contract** = Playwright `contract` project (intercepted API), **SQL** = PGlite suites
in `supabase/tests`, **Unit** = Jest, **Manual** = inspected in the browser.

## Defects found and fixed in this phase

| Finding                                                                                                              | Effect                                                                               | Fix                                                                                                                                 |
| -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Closure final confirmation was dropped while the first step was still refreshing (`run` returned early while `busy`) | A tap on "Confirm" silently did nothing and the dialog vanished; Judging stayed open | `JudgingScreen`: keep the dialog open while busy; E2E `zz-closure`                                                                  |
| First mentor-code issue asked "previous sessions will stop working"                                                  | Misleading confirmation for a code that had no predecessor                           | `AdminScreen`: confirm only on regeneration                                                                                         |
| Team lists came back in UUID order                                                                                   | Legacy lists sorted by name; users saw random order                                  | `sortTeams` (name, then numeric id) in Filming, Judging, pager, admin                                                               |
| Search ignored country names                                                                                         | Legacy searched "team or country"; only the ISO code was matched                     | `countryName` in Filming and pager searches                                                                                         |
| Admin users list had no search or multi-select                                                                       | Legacy had search, select-all and bulk edit                                          | Search, select, "Edit N selected" in `AdminScreen`                                                                                  |
| Pager history could not be filtered                                                                                  | Legacy filtered recent pages by team                                                 | "Filter messages by team"                                                                                                           |
| Status badges were all neutral; no progress bar; header not per design                                               | Design system sections 6–8                                                           | Tone-aware `Badge` (AA text colours), `ProgressBar`, shared `AppHeader`; legacy `atoms/` and `theme/` (old palette, unused) removed |
| Mock seed marked the wrong Filming template                                                                          | Coverage showed 0 captured                                                           | Seed uses the "Step & Repeat" template                                                                                              |

devices), push delivery, PostgREST behaviour, simultaneous-connection races and
physical data deletion remain unverified. The mock is for development only.
