# Snapshot da documentação FGC

Preparado em 19/09/2026. Fonte canônica de edição: `contexts/` na raiz do workspace, fora do repositório `fgc-app`. Esta cópia preserva a árvore completa e os links relativos para consulta em checkout isolado.

Comece pelo [índice](fgc-mvp/README.md), pelo [fechamento das definições](fgc-mvp/fechamento.md) e pela [preparação operacional](fgc-mvp/prontidao-operacional.md).

Não editar este snapshot como fonte independente. Após alterar a fonte canônica, copiar novamente sua árvore, reconciliar arquivos removidos e regenerar o manifesto. `manifest.json` registra caminho relativo, tamanho e SHA-256 de cada arquivo copiado; exclui somente este README e o próprio manifesto. Compare os hashes dos arquivos com o manifesto e, quando disponível, com a fonte canônica.

Relatórios de revisão e registros históricos preservam o estado da data em que foram escritos; correções posteriores estão consolidadas em `.memlog.md`, decisões D01–D74 e contratos atuais. Mapas do legado não comprovam implementação.

Snapshot local não equivale a commit, push, acesso da equipe, aplicativo implementado ou ambiente provisionado. As pendências de execução permanecem explícitas.
